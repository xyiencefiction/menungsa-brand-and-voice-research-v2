# Menungsa Writing Guideline & Studio

Interactive writing guidelines, voice foundations, word guide, and copy sandbox for the **Menungsa** brand voice.

## Features
- **Writing Studio**: Interactive framing matrix and communication context guidelines.
- **Word Guide**: Curated vocabulary, approved/discouraged phrasing, Indonesian nuances, and register map.
- **Copy Sandbox**: Real-time copy testing, tone checks, and interactive feedback.
- **Voice Foundations**: Core brand pillars, resonance spectra, and stylistic values.
- **Tactile Sound System**: Procedural Web Audio API sound micro-feedback.

## Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS
- Lucide React

## Development
```bash
npm install
npm run dev
```

## Production Build & Lint
